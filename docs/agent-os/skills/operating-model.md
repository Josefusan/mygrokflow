# operating-model

1. Read `docs/agent-os/AGENTS.md` and `TOOLS.md`.
2. Load all `context/` files. Treat them as source of truth.
3. Pull only the named role. CEO org stays idle unless named.
4. Load only that role’s skills.
5. Work in at most 6 concurrent rooms.
6. Stop before merge, deploy, spend, or public post — founder gate.
