# delegation

1. Name the role (file in `roles/`). No anonymous “the team.”
2. Brief: outcome, constraints, skills to load, MCP allowed.
3. Point at context files; do not paste novels.
4. Cap rooms at 6. Do not open a new room if one already owns the work.
5. Named pull. CEO org idle unless the brief names CEO.
6. Return work for founder review. Do not merge.
