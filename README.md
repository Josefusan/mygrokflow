# MyGrokFlow

Marketing site for mygrokflow.com.

MyGrokFlow designs and ships high-ticket AI automations for founders, software engineers, and high-earning operators.

Promise: We take a painful recurring workflow and turn it into a system that runs without you.

Static Next.js App Router landing page. No auth, no database, no CMS.

Primary CTA opens email to clarktechventures@gmail.com (subject: MyGrokFlow diagnostic).

## Stack

- Next.js App Router and TypeScript
- Tailwind CSS v4
- shadcn/ui

## Local

See package.json scripts. Standard Next.js app.

## Vercel

Import Josefusan/mygrokflow. Next.js defaults. No environment variables. Attach the domain when DNS is ready. Single route /. Dark by default.
