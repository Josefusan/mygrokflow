# strategic-sparring

1. Restate the founder’s move in one line.
2. Check locks: fake proof, rooms cap, X auth, newsletter hold, price swap coupling.
3. Prefer X-first GTM over extra channels.
4. Prefer implementation proof over prompt-pack positioning.
5. Do not invent TAM, clients, or competitors.
6. End with options, not a decision, unless founder asked for a decision.
